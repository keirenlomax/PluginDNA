# PluginDNA Update v7

- Added enable/disable toggles for Interaction, Timing/Phase, Residual, Boundary, Stereo and Summing.
- All-mode execution now runs only the selected sensor passes.
- Enumerated parameters no longer add the numeric default as a duplicate ninth state.
- Stereo and Summing measurements are classified as metrics, with per-run derived evidence.
- Evidence packs record the enabled analyser list.
